# aicodeline

让"**一个 AI 干活,另外几个互不知情的 AI 独立验收**"变成一条指令的编排技能包,面向 [ZCode](https://zcode.pub) 使用。

An orchestration skill pack for ZCode: one AI does the work, several independent AIs review it. (中文文档为主体)

## 它解决什么问题

AI 写的代码,AI 自己检查不出毛病——自己安排的方案,自己看不出问题。这个包把活儿拆成两拨人:

- **干活的**:一个 AI 负责实现(写代码、写文档、做图);
- **验收的**:几个**互相不通气、和干活的也不是同一个模型**的 AI 各自独立检查,外加一条可插拔的机器检查命令兜底;
- **你(或主对话的管理员)**:只在最后拍板"通过/打回",合并收尾。

不管哪种方式,改动都在独立的副本(git 工作树/分支)里进行,验收通过才合并回你的项目——主目录不会被直接乱改。

检查的规矩都替你想好了:审查者只能看不能改、给两路的材料必须一模一样(防止一个看的多一个看的少)、复核方每轮必须自己设计一个"干活的没测过的刁钻场景"去试(防止只跑现成测试走过场)。

## 四种工作方式

先问两个问题(做什么类型的事 × 用哪种跑法),然后翻对应的手册照着干:

| | 派助手干(成熟) | 后台工作流跑(尝鲜) |
|---|---|---|
| **批量票据**(.scratch 工单) | modes/aicode-mainother.md | modes/aicode-mainother-workflow.md |
| **单件事**(改个功能/写份文档/做个调研) | modes/aicode-mainother-general.md | modes/aicode-mainother-general-workflow.md |

- **派助手干**:主对话像领导一样一个一个派活、收报告,随时插话;
- **后台工作流跑**:整段流程打包成一个后台任务自动跑完——中途卡住会直接向你提问、每完成一步都有进度记录、跑一半挂了修好能接着跑不重花钱。

## 用到的 ZCode 特性

- **技能系统**:整个包只注册一个入口技能(aicodeline),四份手册放在包内 `modes/` 文件夹按需读取——你的技能列表只多一条,不多四个;
- **派助手干**用到:子智能体派发(可指定不同类型)、后台运行与发消息唤醒、结构化问答;
- **后台工作流跑**用到:ZCode 的动态工作流——**给每个小 AI 单独指定不同模型**(验收方和干活的不是同一个模型,这是"独立检查"成立的前提)、小 AI 中途直接向你提问、命令真跑真算(测试没过就是没过,不听 AI 转述)、失败后从断点续跑。需要较新的 ZCode 版本(2026-10 前后支持单指定模型),详见 docs/platform.md。

## 安装

1. 把整个 aicodeline 文件夹拷进你的技能目录(如 `~/.zcode/skills/`);
2. 重启会话;
3. 对 AI 说"用 aicodeline"。

## 首次使用

AI 会自动做一次"环境适配":查你机器上有哪些可用模型和助手 → 按规矩筛出候选人(比如"验收的必须和干活的不是同一个模型、要看图的必须会看图") → 把你机器上配好的**全部模型列成带编号的清单**,再把要定的事排成 A、B、C 几个问题,你**直接打字回答**(比如"B3"就是 B 题选 3 号模型) → 自己记到小本本上(`defaults.md`,已被排除在 git 之外)。

之后每次用,它先翻小本本直接开工;想换人,说一句"以后验收的换成某某"就行,**全程不用手动改任何文件**。选工作流模式时还会多问一句**思考强度**——默认全部用所选模型支持的最高档,想省时间可以说一声改低。

## 换你自己的代码检查工具

批量票据和代码类任务默认加跑"机器初审"(一条独立的检查命令,给代码挑毛病并按严重程度分级)。默认没有指定工具——你告诉它你用什么(接入范例见 examples/),它登记进小本本;不接也行,少了这路但两路 AI 审查照常。

## 目录结构

```
aicodeline/
├── SKILL.md        入口:环境适配 + 两问分流(唯一注册的技能)
├── modes/          四份工作手册(按需读取,不单独注册)
├── appendix/       两份兜底规范:工程纪律 / 工作树操作(没装同类技能时用)
├── examples/       机器初审工具的接入范例
├── docs/           设计理念 / 平台要求 / 个性化指南
└── CHANGELOG.md    更新日志
```

`defaults.md`(本机配置)由 AI 自动创建维护,不进 git。
